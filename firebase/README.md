# firebase/ — Study Notes App backend (P2a)

Rules, schemas, emulator tests and the account-deletion module. Emulator only (`demo-studynotes`).

```bash
npm ci          # exact pinned versions
npm test        # emulators + all tests (needs Java 21+)
npm run gate    # typecheck + lint + tests + audit (fails on high/critical)
```
